# Apps

`apps/` stays top-level. It is the right home for buildable Wharfie applications, dogfood manifests, and reference artifacts that exercise the CLI/runtime end to end.

Today it contains `wharfie-cli`, the self-hosted app used to build the standalone Wharfie executable.

Historical "Wharfie v1" refers to the old Athena/table-oriented product, not this self-hosted CLI app.
