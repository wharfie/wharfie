# Wharfie Application Structure

Wharfie applications are normal TypeScript or JavaScript projects with a
developer-owned CLI and a `wharfie.app.js` manifest. The manifest identifies the
CLI entrypoint, durable activities, runtime resource needs, and package targets.

See the current [Application Structure](../docs/src/assets/markdown/project-structure.md)
guide for a minimal layout and commands that work against the shipped CLI.
